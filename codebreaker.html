How to play Code Breaker

  1. Each of four positions can contain A, B, C, D, E or F. Tap a position to cycle its letter, then press Check code to submit.
  2. Exact counts letters in the correct positions. Other place counts correct letters in different positions, without double-counting a repeated letter.
  3. You have ten submitted guesses. Four exact positions wins. Letters may repeat in the secret. After the tenth unsuccessful guess, the code is revealed. New game creates a fresh code.

Code Breaker practice guide

Treat every result as a constraint

Feedback reports totals rather than identifying individual slots. A guess with one exact match does not tell you which letter is exact. Compare several guesses to narrow the possibilities. Repeated letters need care: the game counts each occurrence only once, so guessing four copies of a letter does not multiply a single occurrence in the secret.

A repeated letter is present only once

Suppose the secret is A, B, C, D and your guess is A, A, E, F. The first A is exact. The second A does not earn an Other place match because the secret has no unused second A. The result is one exact and zero elsewhere. Use that distinction when deciding whether to repeat a letter.

A focused practice session

  1. Start with a guess that tests several letters.
  2. Before submitting again, state which possibility the new guess will distinguish.
  3. Review the whole feedback table before assuming a slot is solved.

What to keep in mind

Secrets use six letters, four slots and repeated letters. The browser record is the fewest submitted guesses for a solved code; different secrets can require different amounts of deduction.
