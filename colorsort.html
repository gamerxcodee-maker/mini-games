Color Sort Puzzle

Make room, uncover a buried colour, and bring each letter home. A calm sorting puzzle with no timer.

Select a tube, then its destination. Each valid move transfers one top counter. Letters identify colours without relying on colour alone.

How to play Color Sort Puzzle

  1. Put all four counters of each letter into a single tube. The two spare tubes may be empty when you finish. A partial tube of one colour is not yet complete.
  2. Select a nonempty source, then an empty tube or one with the same top letter. The destination must have space. Only one top counter moves per action. Select the same source again to cancel.
  3. Undo reverses up to 100 moves made since the current visit or restart. Restart level restores the same starting arrangement; it does not generate a different puzzle.
  4. Next level unlocks after solving. Later levels introduce more colours, up to seven. Your current arrangement, level, move count and per-level bests save in this browser when storage is available. Undo history resets on reload.

Color Sort Puzzle practice guide

Treat an empty tube as working space

A spare tube can hold a counter that is blocking the colour you need. Before using one, inspect the top of every tube and identify a possible home for that counter later. Filling both spare tubes with unrelated colours may leave you unable to uncover a useful match. This version moves exactly one counter at a time, so a group of matching counters can be divided when that creates space. Letters match colours, making the top counter readable without relying only on its hue.

Uncover a buried matching counter

Imagine one tube contains A, A, B from bottom to top, while another has B on top and one free space. Move the blocking B onto that matching B. The first tube now exposes A, making it a possible destination for another A. That single move improves two groups. Moving the B into a spare tube is legal too, but it uses working space without making the B group more complete.

A focused practice session

  1. Before moving, name the counter you want to uncover and where the blocking counter could go.
  2. If you run out of useful moves, use Undo and try keeping one spare tube empty for longer.
  3. Restart the same level after solving it and compare your move total with your saved best.

What to keep in mind

A tube is finished only when all four of its counters match. Levels are generated by reversible moves from a solved arrangement. Undo history is limited to 100 moves and resets on reload; current board progress saves separately.
