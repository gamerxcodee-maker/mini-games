Make a short session useful

Read the controls first, choose one habit to practise and review a specific decision after the run. Compare results on the same difficulty and input method. Random layouts and opponents change, so a score difference alone does not tell you which habit improved.

Saved records usually belong to the browser where you played. See each game’s instructions for the exact scoring, mode and storage behaviour. For a rule that seems different from the guide, use the contact page to report the game and the situation.
